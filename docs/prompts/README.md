# Prompts

Prompts prontos para colar num agente de código (Claude Code, Codex, etc.) que
tenha acesso ao diretório do projeto.

- [00-setup.md](00-setup.md): instalar o CommentFlow do zero e ligar o Instagram
  (o agente faz a parte do computador e conduz a pessoa pela Meta).
- [13-revisao-seguranca.md](13-revisao-seguranca.md): revisão de segurança só
  leitura, do projeto inteiro ou de uma mudança (para quem desenvolve).

Para o passo a passo manual (feito para leigo), veja o [GUIA.md](../GUIA.md).
